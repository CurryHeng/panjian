# 盘见首版设计

用户已选定 AI＋影像方向，批准先建立精彩回合剪辑、再添加可编辑讲解。团队具备前后端与基础 Python 能力，可获取飞盘视频和专业反馈。

首个交付单元是仅本机使用的视频剪辑工作台。FastAPI 提供上传、项目读写、后台导出与受控文件下载；HTML/CSS/JavaScript 提供素材播放器与片段列表；FFmpeg 负责探测和重新编码。采用 imageio-ffmpeg 提供的可执行文件，避免要求系统预装 FFmpeg。数据保存在本地 data/，不发送到模型或外部服务。

流程：上传视频→读取时长→人工选择回合→编辑与排序→保存项目→后台生成 MP4→下载。AI 候选后续复用同一片段结构。

片段包含 id、start、end、title、notes。起止时间单位为秒，必须为有限数，满足 0≤start<end≤素材时长。标题和备注是编辑元数据，首版不烧录到视频。导出逐段重新编码为 H.264/AAC，保持顺序，兼容无音轨视频；不支持跨素材拼接。

使用随机 ID 定位服务器文件，不接受任意本地路径。限制上传大小为 2 GiB，先写临时文件，探测失败后清理。服务只绑定 127.0.0.1，拒绝跨源变更；无身份验证，不能作为公网服务。后台任务状态为 queued/running/completed/failed；进程重启时未完成任务标记失败。错误显示给用户，详细日志保留服务端。

验证：用有音轨及无音轨的合成视频验证上传、重启读取、边界拒绝、顺序剪辑与输出可解码性；不以合成素材声称飞盘识别能力。
