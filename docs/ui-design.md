# 界面视觉规范

风格定位：**运动品牌海报 + 现代杂志排版**。不是 SaaS 后台，不是游戏界面。
改任何界面代码前先读完本文件；与 `AGENTS.md` 冲突时以 `AGENTS.md` 的硬规则为准。

## 一、颜色

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#0a0a0a` | 页面底色，唯一背景 |
| `--panel` | `#121212` | 区块底（时间轴等） |
| `--panel-2` | `#1a1a1a` | 输入框底 |
| `--line` | `#2a2a2a` | 1px 分割线、边框 |
| `--text` | `#f4f4f0` | 主文字 |
| `--muted` | `#a0a09a` | 次要文字 |
| `--lime` | `#c8f23a` | **唯一强调色** |
| `--danger` | `#ff5a4a` | 删除、错误 |

- 强调色只出现在四处：主按钮、当前导航、播放头、大号片段序号（以及一处大字色块）。
- 禁止出现第二强调色。需要"次级高亮"时，用白色吃满或降低不透明度，不要换色相。

## 二、字体

- 展示字 `--display`：`Impact` 系窄粗体，全大写，字距收紧。只用于 h1、h2、大号序号、时长数字。
- 正文 `--body`：系统中文黑体栈。不引入 Google Fonts 或任何 CDN 字体。
- 尺度：h1 `clamp(56px, 9.5vw, 148px)`，h2 `22px`，正文 `14px`，辅助 `12px`。**最小 12px**。
- 少用粗细混排：要么 400（Impact 只有 400），要么 800（按钮）。

## 三、空间

- 页面左右留白 40px（窄屏 24px），内容最大宽 1360px。
- 模块之间靠 1px `--line` 分隔 + 28–40px 留白，不靠卡片。
- 圆角只允许 0 或 2px。禁止胶囊、禁止 8px 以上的圆角。

## 四、构图

- 首屏必须有一处**超大排版**（字号 ≥ 96px 或占宽 ≥ 50%）。
- 允许文字裁切、叠压、竖排、贴边，这是参考风格的核心，不要"居中对称"。
- 双栏用不对称比例（如 1.7 : 0.8），不要 50/50。
- 每个区块的容器形态要有差异；全页面板样式不超过两种。

## 五、禁止清单

- 装饰性投影、内阴影、发光
- 渐变按钮、渐变文字（页面背景的暗角渐变除外）
- 玻璃拟态、毛玻璃
- 卡片套卡片
- emoji 或字符画当图标（`◇ ↗ ▣` 这类）
- 悬浮卡片 + 圆角 + 阴影三件套
- 同色系不同深浅堆五六个灰阶
- 每个区块都带一个左侧彩色竖条

## 六、图片

- 只允许黑白或高对比处理；照片统一 `filter: grayscale(1) contrast(1.25)`。
- 新增图片必须在 `app/static/img/` 下，并在页脚或文档注明作者与授权。
- 优先用产品自己的视频截帧，其次免费图库（Unsplash/Pexels 免费授权）。

## 七、交互态

- hover：翻译 2px、换成白色或强调色，不要缩放。
- focus：2px 强调色 outline，offset 2px。
- disabled：`opacity: .35`，光标 not-allowed。
- 过渡时长 120ms 以内。

## 八、检查清单（改完逐条打勾）

- [ ] 全页只有一种强调色
- [ ] 没有圆角 > 2px 的元素
- [ ] 没有装饰性阴影或渐变按钮
- [ ] 至少有一处超过 96px 的大字
- [ ] 每个区块容器样式有差异，没有卡片套卡片
- [ ] 正文没有小于 12px 的字
- [ ] 宽度 1440px 截图看过，1440 下无横向滚动、无文字重叠
- [ ] 650px 窄屏下导航、表单、时间轴不破版
- [ ] 新图有授权署名
