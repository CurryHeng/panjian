# v0.1 验证记录

日期：2026-11-03。验证对象：本机单用户剪辑工作台，不包含 AI 或 Android。

## 自动化后端验证

命令：`python -m pytest -q --basetemp <本轮专用测试目录> --tb=short`

最终结果：7 passed，耗时 3.73 秒。存在一条上游 Starlette/httpx 弃用提示，不影响本轮测试；尚未消除该依赖提示。

覆盖有音轨/无音轨视频导入、无效素材拒绝、项目恢复、非法区间及非有限数字拒绝、片段保存、空集锦拒绝、按用户指定顺序导出、输出时长与可解码性、音轨有无保持、未知资源返回 404、跨源写入拒绝。

真实编码测试：6 秒红/蓝合成源，选择蓝色 3.5—5 秒后接红色 0.5—1.5 秒，验证输出起始为蓝色，总时长约 2.5 秒。测试素材不代表飞盘识别效果。

## 浏览器验证

使用 Playwright 与本机 Edge 无头浏览器连接真实服务。

已验证：导入合成视频→添加两个片段→修改标题→保存→刷新恢复→生成集锦→显示下载链接；1440 像素桌面与 390 像素手机布局无横向溢出，过程中无 JavaScript 未捕获错误。已检查桌面及手机截图。

代码审查发现保存期间编辑/切换项目可能混淆状态。已先通过延迟保存响应复现，再锁定保存期间的相关操作，回归验证通过。

`node --check app/static/app.js` 和 `python -m compileall -q app` 退出码均为 0；真实 GET /api/health 返回 ok。

## 未覆盖及限制

- 未获得真实飞盘素材，未验证任何 AI 精彩事件推荐、战术判断或识别准确率。
- 未做长视频、大文件压力测试、运动视频画质评价、浏览器全兼容测试。
- 尚无任务百分比、取消、删除、空间配额、断点续传或多用户隔离。
- 浏览器支持的解码格式与 FFmpeg 不完全相同，建议使用 H.264 MP4。
- 当前实现仅支持单素材多个片段，标题和备注不写入成片。
