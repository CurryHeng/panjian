# 盘见 · 飞盘影像工作台 v0.2

上传一段比赛视频即可在本机生成可播放、下载的第一版集锦。程序以 NanoDet 的人物检测信号和画面运动量选择候选，保留收尾、合并重叠，再按原片顺序导出。进球、接盘和战术标签仍需人工判断。模型权重及许可随 app/models 分发，来自 [OpenCV Zoo NanoDet](https://github.com/opencv/opencv_zoo/tree/main/models/object_detection_nanodet)。

## Windows 启动

在本目录打开 PowerShell（需要 Python 3.11+）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8765
```

浏览器打开 http://127.0.0.1:8765 。依赖已安装时，也可执行 `powershell -ExecutionPolicy Bypass -File .\start.ps1`（使用 PATH 中的 Python）。停止服务按 Ctrl+C；若正在导出，将等待当前任务结束。首次安装 imageio-ffmpeg 包会下载内含的视频工具，无需额外配置 FFmpeg。

## 操作

1. 点击“上传并生成集锦”，选择比赛视频。等待自动分析和编码完成后，即可播放或下载初版。后续步骤用于可选精修。
2. 在播放器定位回合，通过“使用当前播放时间”标记开始和结束，或输入秒数。
3. 添加片段，修改起止、标题和备注，用上下按钮调整顺序；预览会在片段结束时暂停。
4. 想看动作收尾，点击“预览后两秒”。决定保留时再点“延长两秒”。临近原片结尾时只取剩余时长。
5. 若两段属于同一次配合，将它们排在一起，点击前一张卡的“合并下一段”。时间相接或重叠时可合并，标题和备注随片段保存。
6. 点击保存；导出时也会自动保存。未保存的编辑关闭页面会丢失。
7. 点击生成精彩集锦，等待编码完成后下载 MP4。刷新后可在该项目找回完成的导出。

标题和备注仅用于素材管理，不烧录到视频。导出保留原声音（素材存在音轨时），不加配乐。仅支持同一个源视频中的多片段合成。

## 验证

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q --basetemp .pytest-temp-local
node --check app/static/app.js
```

pytest 的 basetemp 应使用本项目内专门用于测试的目录，测试框架会清理该目录。测试生成的红/蓝视频只验证编码、排序和时长，不证明任何飞盘理解能力。

## 默认末尾保留规则
每次自动生成时额外保留源视频最后10秒，不足10秒保留全片；与推荐片段重叠或相接则合并。即使没有模型候选，也会生成末尾片段，并在备注中标注“拍摄习惯保留，非精彩识别结论”。edit-plan.json保存规则来源及tail_only/model_and_tail状态。人工保存的片段不受此规则强制改写。更新代码后需重启服务才对新上传生效。

## 当前工作区选择性回溯
本目录为新的开发副本，旧目录只读参考。自动生成默认开启5秒回看、至少2秒回溯，重新合并避免重复，保留末尾十秒；历史项目不自动重算。
在本目录运行 `.\start.ps1`。该脚本固定新上传数据到本目录data，监听127.0.0.1:8765。如旧服务占用端口，请先关闭旧服务或用另一个端口启动新副本；本次未自动终止旧进程。
回退：在启动前设置 `$env:PANJIAN_START_BACKTRACK = '0'`；重新开启设为 `'1'`。此开关只影响新自动任务。
新阶段成片与报告见上级“阶段输出/选择性回溯接入”。
